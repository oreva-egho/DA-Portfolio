Healthcare & Emergency Services

HealthResponse Ltd: Real-Time Incident Analytics System

Problem: HealthResponse Ltd lacked a reliable way to monitor SLA compliance and dispatcher accountability across a high-volume incident caseload. Data & approach: Ingested 3,000 incident records via MS Forms and Google Sheets, cleaned and structured the data using Power Automate, then built a two-page Looker Studio executive dashboard. SLA compliance was calculated using a priority-weighted CASE WHEN formula to correctly account for P1–P4 response windows. My role: Solo analyst — data modelling, formula design, dashboard build, and written executive narrative.

✓SLA compliance reported at 71.07% — derived from a priority-aware formula that distinguishes P1–P4 response thresholds, not a simple pass/fail count
✓Dispatcher performance table surfacing T. Wilson (131 SLA breaches) as the highest-risk operator, enabling targeted intervention
✓Executive insight panel translating raw metrics into plain-English board-level narrative using an Observation → Context → Action framework
Looker Studio Power Automate Google Sheets MS Forms SLA Analysis
Manufacturing & Operations

GreenTech Manufacturing: Production Downtime Optimisation

Problem: GreenTech's operations team had no consistent visibility into what was causing production stoppages, which were estimated to cost $1.5M annually across four eco-cleaning product lines. Data & approach: Queried production schedule and downtime log tables in SQL Server using joins and aggregation to rank failure categories by frequency and duration. Findings were surfaced through a Power BI dashboard replacing a 48-hour manual Excel process. My role: Solo analyst — SQL query design, data cleaning, root cause categorisation, and dashboard delivery.

✓Top 3 downtime causes identified (equipment failure, operator error, scheduling gaps), accounting for 68% of all production stoppages
✓Power BI dashboard delivered real-time visibility, replacing a process that previously took 48 hours of manual reporting
✓Recommendations prioritised by estimated cost impact, forming a $1.5M savings roadmap for operations leadership
SQL Server Power BI Data Cleaning Root Cause Analysis
Media & Entertainment

StreamWave Entertainment: Viewer Engagement & Genre Analysis

Problem: StreamWave's content team was allocating budget across genres without reliable data on which drove long-term engagement and retention across their 150M+ subscriber base. Data & approach: Cleaned and restructured multi-sheet viewing data in Excel using Power Query, built a composite performance index weighting watch-time, retention rate, and subscriber growth, then surfaced findings in an interactive dashboard with dynamic slicers by genre and region. My role: Solo analyst — data modelling, index design, dashboard build, and written content strategy recommendations.

✓Drama and Sci-Fi ranked highest on the composite performance index — strong watch-time and above-average 90-day retention rates
✓Interactive Excel dashboard with dynamic slicers reduced ad-hoc genre reporting requests by an estimated 40%
✓Genre performance findings directly referenced in content acquisition and marketing spend decisions for the following budget cycle
